# five-air-media
This repository contains the media production capstone project developed by our team as part of Digital Egypt Pioneers Initiative (DEPI). Our project focuses on raising awareness and providing insights into slimming injections (weight loss injections), covering their impact, usage, and health considerations through engaging visual and digital media
